// IMPLEMENTATION · 实现方案

方案: CSS @media print 隐藏非内容元素 + JavaScript printPreview() 函数。
思路：用户点击"打印"按钮 → 切换到 Preview Tab → 触发浏览器的打印对话框 → CSS media print 规则只显示预览区。
用户操作流: 点击打印 → 切换到预览Tab → window.print() → 仅预览区打印
CSS media print 规则（放在 common.css 末尾）:
/* ====== Print: 只打印预览区 · ONLY PREVIEW ====== */ @media print { /* 隐藏所有 UI 元素 */ .global-nav, .sidebar, .tmpl-panel, .tab-bar, .doc-header, .action-bar, .tmpl-bar, #panel-edit, #panel-history, .bottom-cta, .page-footer, .faq-section { display: none !important; } /* 显示预览区 + 重置布局 */ #panel-preview { display: block !important; } .doc-page-content { display: block !important; } .main-content { max-width: 100% !important; padding: 0 !important; } /* 背景强制白色 + 文字黑色 */ body { background: #ffffff !important; color: #000000 !important; } #preview-container { background: #ffffff !important; box-shadow: none !important; } /* A4 横版打印设置 */ @page { size: A4 landscape; margin: 10mm; } }

// PRINT FUNCTION · 打印函数

在 common.js 中新增通用函数，所有 19 个页面共用：
/** 打印当前文档的预览区（仅预览内容） */ function printDoc(dt) { var lang = getLang(); var label = DOC_META[dt].titleZh || 'Document'; // 1. 确保 Preview tab 内容已渲染 if (typeof renderPreview === 'function') { renderPreview(); } // 2. 切换到 Preview tab var tabPreview = document.getElementById('tab-preview'); if (tabPreview) tabPreview.click(); // 3. 短暂等待 DOM 刷新后调起打印 setTimeout(function() { var oldTitle = document.title; document.title = label; window.print(); document.title = oldTitle; }, 200); } /** 打印纯预览 HTML（iframe 方式，不影响当前页面状态） */ function printDocClean(previewHTML, title) { var iframe = document.createElement('iframe'); iframe.style.position = 'fixed'; iframe.style.right = '0'; iframe.style.bottom = '0'; iframe.style.width = '0'; iframe.style.height = '0'; iframe.style.border = 'none'; document.body.appendChild(iframe); var doc = iframe.contentWindow.document; doc.open(); doc.write('<!DOCTYPE html><html><head><meta charset="UTF-8">' + '<title>' + (title || 'Document') + '</title>' + '<style>body{font-family:Arial,sans-serif;background:#fff;margin:0;padding:10mm}' + '@page{size:A4 landscape;margin:10mm}' + 'table{border-collapse:collapse;width:100%}' + 'th,td{border:1px solid #000;padding:4px 6px;font-size:11px}' + '</style></head><body>' + previewHTML + '</body></html>'); doc.close(); iframe.contentWindow.focus(); iframe.contentWindow.print(); setTimeout(function() { document.body.removeChild(iframe); }, 1000); }

// ENTRY POINTS · 打印入口

  • Preview Tab 内: 在预览区的 action bar 中添加"打印"按钮，放在"导出 PDF"旁边
  • 全局导航: 右上角添加打印机图标按钮（仅当用户在 Preview Tab 时高亮）
  • 快捷键: 可选绑定 Ctrl+Shift+P → printDoc(DT)，避免与浏览器 Ctrl+P 冲突
两种打印方式对比:
printDoc(dt) · 简单方式
切换 Tab → 触发浏览器 print → CSS media print 隐藏 UI。
优点: 实现简单，复用了预览渲染。
缺点: 短暂切换到 Preview Tab 再切回；暗色模式下打印可能有白色背景问题（CSS 解决）。
printDocClean(html, title) · iframe 方式
创建隐藏 iframe → 写入预览 HTML + @page CSS → iframe 内打印。
优点: 不切换 Tab，不干扰编辑状态；完全干净的打印环境。
缺点: 多一次 DOM 写入；iframe 中的字体可能需要单独指定。

// DARK MODE HANDLING · 暗色模式

  • 当前 `printDoc()` 的 CSS `@media print` 规则中强制 `body { background: #fff; color: #000 }`，所以暗色模式下打印也会是正常的白色文档
  • iframe 方案 (`printDocClean`) 天然不受页面暗色模式影响——iframe 内是一个独立的全新 document
