# Trade Contract 预览模板优化 — 设计文档

## 概述

参照 `hetong.html` 合同样式模板，优化 Trade Contract (trade-contract.html) 的预览模板风格，同时调整表单编辑区的模块布局，新增"装运条款"模块。

## 数据模型变更

### `getDefaultDoc('trade_contract')` 新增字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `packagingType` | string | `''` | 包装种类（短文本） |
| `shipmentTime` | string | `''` | 装运时间（短文本，非日期格式） |
| `partialTransshipment` | string | `''` | 分批与转船条款（短文本，~10-30字） |

### 现有字段移动

- `portOfLoading`（装货港）— 从"合同信息"移至"装运条款"
- `portOfDischarge`（卸货港）— 从"合同信息"移至"装运条款"

## 表单编辑区变更

### 合同信息模块（移除装货港、卸货港后）

```
┌─ 合同信息 ──────────────────────────────────────┐
│ 合同号    签署日期    签署地    货币              │
│ 付款条款   交货条款   装船日期                    │
└──────────────────────────────────────────────────┘
```

### 新增装运条款模块（插入在商品明细之前）

```
┌─ 装运条款 ──────────────────────────────────────┐
│ 包装种类 ______   装运时间 ______                 │
│ 装货港 ______     卸货港 ______                  │
│ 分批与转船条款 ________________________________ │
└──────────────────────────────────────────────────┘
```

### 模块顺序（编辑区由上到下）

1. 合同信息（简化后）
2. 装运条款（🆕 新增，portOfLoading/discharge 移入）
3. 卖方信息
4. 买方信息
5. 商品明细
6. 商业条款（不变）
7. 违约条款与签署（不变）

## 预览样式规则（参照 hetong.html）

| 元素 | 样式 |
|------|------|
| 标题 | Georgia serif, 32px, #1d3557, 居中, 3px #1d3557 底部边框 |
| 卖/买方区块标题 | 14px #1d3557, #a8dadc 底部边框, 大写 |
| 卖/买方内容 | 13px, line-height 1.5, #333 |
| 合同信息 | 右侧固定 260px 列, label 135px 加粗深蓝, value #222 |
| 商品表表头 | #1d3557 背景, 白色文字, 全边框 |
| 商品表行 | 鼠标悬停 #f1faee |
| 条款展示 — 短文本 | `标签: 内容` 一行内显示，标签深蓝加粗 |
| 条款展示 — 长文本 | 标签在上行，内容在下行 |
| 签署区 | 左右两列，签名框 1px #1d3557 边框, #fafbfc 背景 |
| 总金额行 | #f8f9fa 背景, 深蓝加粗 |

## 实施范围

### 文件
1. **common.js** — `getDefaultDoc('trade_contract')` 添加 3 个新字段
2. **trade-contract.html** — `renderForm()` 和 `renderPreview()` 重写

### 不涉及
- common.css — 无需新增 CSS，现有 `.invoice-preview` 已涵盖 #1d3557 主题
- 模板系统 — 本次暂不加入模板字段配置（与 Commercial Quotation 方案一致，后续迭代）

## 注意事项

- `loadSample()` 需要为新字段添加示例值
- 表单编辑区注意字段顺序与 preview 一致
- 所有改动在同文件 `trade-contract.html` 内部完成
- 使用现有 `esc()`、`pv()` 等辅助函数
